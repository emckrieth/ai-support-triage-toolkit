# Sample Output

After running the demo, the tool creates:

- `output/triage-results.json`
- `output/support-summary.md`

Example result:

```text
INC-48304: Endpoint Disk Pressure Remediation
Confidence: 93 percent
Evidence coverage: 100 percent
Next owner: Endpoint Operations
```

The dashboard then shows:

- Recommended runbook
- Evidence strength
- Baseline outlier checks
- Recommended actions
- Sanitized evidence preview
